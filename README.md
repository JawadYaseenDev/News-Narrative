## AI-Powered News Bias Detection, Credibility Scoring, and Propaganda Analysis System

With the rapid growth of digital news, it has become harder for readers to identify political bias, misinformation, and different ways of presenting the same story.

**News Narrative** is a web-based AI system developed to detect and visualize political bias in news content from major Pakistani media outlets.

The system uses **Natural Language Processing (NLP)** and **Machine Learning (ML)** techniques to classify news articles on a **Left–Centre–Right** scale. It also analyzes how news stories are framed and presents the results through an interactive dashboard.

## Key Features

* **Article-Level Bias Classification:** Automatically classifies individual news articles as Left, Centre, or Right.
* **Outlet-Level Visualization:** Provides an interactive dashboard to visualize the bias position and coverage intensity of different news outlets across various topics.
* **Narrative Framing Detection:** Analyzes how news stories are presented, including emotional and rhetorical framing, to help compare coverage from different outlets.
* **Simplified Summaries:** Generates easy-to-understand summaries so users can compare different news reports without reading every full article.
* **Explainable AI:** Focuses on making AI-based classifications easier to understand and provides more transparency to users.

## Technology Stack

* **Frontend:** React.js, Tailwind CSS
* **Backend & AI:** Python, NLP, Machine Learning
* **Database:** Relational Database for storing articles and analysis results

## Objectives

1. Make media bias easier to understand for everyday readers in Pakistan.
2. Support informed news consumption and help improve media literacy.
3. Demonstrate how AI can be used to solve real-world sociopolitical problems.
